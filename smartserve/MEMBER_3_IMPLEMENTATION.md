## 🗄️ Firestore Collections Structure

You need to create the following collections in Firestore:

### 1. **orders** Collection
```
{
  orderId: string (auto-generated by Firestore)
  userId: string (user's UID)
  userName: string
  items: array[
    {
      itemId: string
      name: string
      price: number
      imageUrl: string
      quantity: number
      customizations: {
        spice_level: string (Mild/Medium/Hot)
        size: string (Regular/Large/Venti)
        sweetness: string (Normal/Extra Sweet/Add Ice Cream)
      }
    }
  ]
  totalAmount: number
  status: string (pending|confirmed|preparing|ready|completed|cancelled)
  createdAt: timestamp
  scheduledTime: timestamp
  notes: string (optional)
  paymentMethod: string (cod|upi|wallet|card)
  paymentStatus: string (pending|completed|failed)
  estimatedPrepTime: number (in minutes)
  staffAssignedId: string (optional, for future staff assignment)
}
```

### 2. **transactions** Collection
```
{
  transactionId: string (auto-generated)
  orderId: string (reference to order)
  userId: string (user's UID)
  amount: number
  paymentMethod: string (upi|wallet|cod|card)
  status: string (pending|completed|failed|refunded)
  createdAt: timestamp
  razorpayOrderId: string (optional)
  razorpayPaymentId: string (optional)
  razorpaySignature: string (optional)
  failureReason: string (optional)
  receiptUrl: string (optional)
}
```

### 3. **users** Collection (Update existing)
Add to user documents:
```
{
  ... existing fields ...
  walletBalance: number (default: 0.0)
}
```

## 🚀 How to Use

### For Customers (User Role)

1. **Browse Menu**
   - Navigate to Menu tab in StudentMainScreen
   - Open menu item details

2. **Add to Cart**
   - Customize item (spice level, size, sweetness)
   - Adjust quantity
   - Click "Add" button
   - Item added with customizations

3. **View Cart**
   - Click Cart tab in StudentMainScreen
   - View all items with customizations
   - Adjust quantities or remove items

4. **Checkout**
   - Click "Proceed to Checkout"
   - Select delivery time (now or future)
   - Choose payment method:
     - Cash on Delivery (COD)
     - UPI/Phone Pay
     - SmartServe Wallet
     - Debit/Credit Card
   - Add special instructions (optional)
   - Review order and payment

5. **Track Order**
   - View order in real-time
   - See status progression (Pending → Confirmed → Preparing → Ready → Completed)
   - View order details, items, and total
   - Cancel order if needed
   - Access transaction receipt

### For Staff (Staff Role)

1. **Switch to Orders Tab**
   - In Staff Dashboard, click "Orders" tab

2. **View Incoming Orders**
   - See all new orders in real-time
   - Filter by status using chips

3. **Manage Orders**
   - Click "Confirm" to accept new order
   - Click "Start Prep" when preparing
   - Click "Ready" when order is ready
   - Click "Complete" when given to customer
   - Click "Reject" to decline order

4. **View Order Details**
   - Click eye icon to see detailed order info
   - View all items and customizations
   - Read special instructions
   - See customer details

## 🔌 Integration Points

### Payment Gateway (Razorpay/Stripe)
The app is structured to support Razorpay in test mode:

1. In `payment_service.dart`, the `generateRazorpayOrderId()` method needs to be connected to actual Razorpay API
2. Transaction records store Razorpay order/payment IDs
3. Payment verification logic is ready to be implemented

**To add Razorpay:**
```dart
// Install: flutter pub add razorpay
// Then implement payment processing in CheckoutScreen
```

### Wallet System
- User wallet balance stored in Firestore under `users` collection
- Add/deduct functions ready to use
- Can be extended with recharge functionality

### Real-time Updates
- All screens use Firestore listeners for real-time data
- Orders update instantly when staff changes status
- Notifications can be added using Firebase Cloud Messaging (FCM)
